## Problem
Small game developers have limited time and money, so choosing the wrong genre or price can hurt a game before it launches.

## What it does
Start-up Solver uses Steam game data to show which genres have the highest ratings, which genres are crowded or underserved, which keep players playing longest, and what games in each genre usually charge.

## How to run it
1. Open the notebook in Google Colab.
2. Upload steam_games.csv from this repo.
3. Run all cells from top to bottom.
